# Current scientific limitations

This is analysis software, not a qualified hardware-cost or FTQC error predictor. Verified simulator experiments do not validate real physical-device models. IBM raw-shot majority decoding is a repetition-code baseline, not an independently calibration-weighted surface-code predictor. Some IBM experiments feature interleaved data/syndrome measurement order outside the current decoder's supported assumptions; excluded jobs must be reported. Fez calibrations are historically measured and can fail a 365-day freshness criterion. Aurora matrix replotting uses the authors' figure workbook, not independently processed optical measurement files. Helios MCMR statistics are extracted from saved author notebook output, not recalculated from `.p` experiment records; no pickle execution is performed. The neutral-atom loss-aware decoder and published d5/d3 factor are not independently reproduced. Four-family conditional architecture envelopes use deliberately toy, non-device parameters. Correlated errors, factory tail latency, routing contention, physical optical/ion/atom constraints and actual universal FT circuits have not been modeled in a verified end-to-end causal pipeline. Source hashes, tests and human review remain required for scientific promotion.

Historical citation and limitation identifier **L21** remains preserved in the archived evidence ledger; this release does not reinterpret its original source claims.

## IBM holdout evidence distinction 

The raw Fez calibration archive contains two authentic calibration timestamps but only one supported decoded timestamp after exclusion of a nonstandard older experiment. Within-job physical-chain holdout predicts an empirical error rate for a disjoint chain using other chains' observed rates; it is neither a later-calibration holdout nor a fit to physical gate/readout/calibration parameters. Distinct physical chains can share correlated noise. Temporally matched calibration-conditioned prediction requires a protocol-matched source split and independent review of the older QASM measurement chronology or additional verified experimental snapshots.
